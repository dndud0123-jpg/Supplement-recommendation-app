# VitaMobile AI

모바일 최적화 맞춤 영양제 어드바이저 — Google Gemini AI 기반

## 로컬 개발

```bash
npm install
npm run dev
```

## 환경변수

| 변수명 | 설명 | 필수 |
|--------|------|------|
| `VITE_GEMINI_API_KEY` | Google Gemini API 키 | 선택 (UI에서 직접 입력 가능) |

## 배포

```bash
npm run build   # dist/ 디렉토리에 정적 빌드 출력
npm run preview # 로컬에서 빌드 결과 미리보기
```
